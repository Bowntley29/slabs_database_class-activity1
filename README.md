# 2. App: Instagram 

1. Hardware: The app uses smartphones such as Android and IOS, laptops for Instagram Web,a data center Meta that stores photos and videos and network devices like a wifi routers.

2. Software: Instagram is a mobile application it can be used via Instagram Web on the internet,its operating systems are Android, iOS, Windows, server software and database system like PostgreSQL that stores user data, AI algorithms for the feed and filters.

3. Data: It collects data facts such as the usernames, useremail, likes, comments, number of followers, photos, videos, reels, timestamps of posts, hashtags, location tags, stories views.

4. People: In this application there are users who post content, viewers, content creators, software developers who build the Instagram application and support team.

5. Process: The user opens app, logs in, creates content, adds filter or caption or hashtags, clicks share, system stores data on server, system applies algorithm to show post to followers, followers like or comment on the post, then the user recieves notifications.

# 3. Data and Information collected by the application:
- User: The post has 1000 likes at 21:15 PM.
- Post: User got 50 likes today.
- User viewed 35 reels in 1 hour.

The system of instagram application reads the raw likes and views of a post. A performance report is shown to the user like: "This post has 5x more engagement than your average posts this week and 50% of likes are from 18-24 year olds." This Information helps the user or creator decide what type of content to post next and helps Instagram's algorithm decide to push the post to more people on the explore page.
